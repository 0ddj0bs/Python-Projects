# Pixel Strike

A compact Contra-inspired 2D side-scrolling shooter built with Python and Pygame.

Features:
- Side-scrolling action with a pixel-art look
- Player movement, jumping, and shooting
- Enemy waves with simple AI
- Score, health, and restart flow
- Parallax background and explosion effects

Controls:
- A / D or Left / Right: move
- W / Up / Space: jump
- J / K: shoot
- ESC: quit

Run:
1. python -m venv .venv
2. source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
3. pip install -r requirements.txt
4. python game.py
